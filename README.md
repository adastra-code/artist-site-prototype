# Сайт художницы — материалы

Папка под будущий сайт художницы. Содержит исследование конкурентов
(сайты художниц: кто успешен, кто нет, что общего у хороших), плейбук
по сборке самого сайта, фотографии работ с веб-версиями и прототип сайта.

**Дата сбора данных:** 15.10.2026

## Публикация

- **Живой прототип сайта:** <https://adastra-code.github.io/artist-site-prototype/>
- **Репозиторий:** <https://github.com/adastra-code/artist-site-prototype>
- **Скачать ZIP:** <https://github.com/adastra-code/artist-site-prototype/archive/refs/heads/master.zip>

> Прототип закрыт от индексации (черновик): `robots.txt` → `Disallow: /`
> и `noindex, nofollow` на всех страницах. Открыть перед запуском:
> `site\deploy-pages.ps1 ... -Index`.

## Структура

| Файл | Что внутри |
|---|---|
| `docs/analysis-artist-websites.md` | Основной аналитический отчёт |
| `docs/site-build-playbook.md` | План сборки сайта: один домен, два пути, главная с галерейным упором |
| `site/` | Прототип сайта (статика, RU): `build.ps1`, `content/`, `dist/` |
| `assets/works/` | Фото работ: оригиналы, WebP-версии и каталог `inventory.csv` |
| `docs/data/sites-technical.csv` | Технические замеры сайтов (доступность, платформа, магазин, SEO) |
| `docs/data/wikipedia-demand.csv` | Спрос по имени (просмотры Википедии), прокси поисковой востребованности |

## Как собирались данные

- Доступность и техника: `curl` — HTTP-код, размер HTML, наличие `viewport`,
  магазина, `robots.txt`, `sitemap.xml`; отдельно проверялись TLS-сертификаты.
- Спрос по имени: официальный API Викимедиа (среднее число просмотров статьи
  в англ. Википедии в месяц, окт. 2024 — сент. 2026).

## Оговорки

- Просмотры Википедии — это спрос **по имени**, а не посещаемость сайта.
- Часть сайтов блокируют ботов (Cloudflare, 403) — они помечены отдельно.
- Некоторые домены не открывались из-за их собственных битых TLS-сертификатов;
  содержимое проверялось в обход проверки сертификата.

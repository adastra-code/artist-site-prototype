## Регенерация веб-версий

```powershell
.\tools\optimize-images.ps1 -Cwebp "C:\путь\к\cwebp.exe"
```

Требуется `cwebp` из пакета **libwebp**
(<https://developers.google.com/speed/webp/download>). Причина внешнего
инструмента: в Windows WIC WebP-**энкодер** отсутствует (Jpeg/Png/Tiff/Heif —
есть, WebP — нет), поэтому стандартными средствами системы WebP не получить.

Скрипт читает `inventory.csv`, берёт качество из колонки `web_q`
(иначе `-WebQuality`, по умолчанию 82) и пропускает записи со
`readiness = duplicate`. Колонки `web_kb` / `thumb_kb` — снимок на момент
импорта, после пересборки могут отличаться.

## Примечания

- **EXIF нет.** Проверено: ни в одном оригинале нет заголовка `Exif`, GPS-меток
  тоже нет (совпадение подстроки `GPS` в `1000009259.jpg` — ложное, внутри
  сжатых данных). Производные WebP метаданных не содержат по умолчанию.
- **`exhibition-01`** — в кадре узнаваемые лица: перед публикацией нужно
  согласие изображённых.
- **Раскладка.** Пропорции работ разные (15 горизонтальных, 11 вертикальных,
  1 квадрат), поэтому сетка превью должна использовать `object-fit: cover`
  либо masonry — иначе работы «поплывут».
- **Нет названий.** Названия, годы, техника и размеры работ отсутствуют;
  слагы (`work-01`…) временные, до присвоения реальных названий.

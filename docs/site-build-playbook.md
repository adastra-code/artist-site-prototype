# Плейбук: сайт художницы (один домен, два пути)

**Дата:** 15.10.2026
**Приоритет:** галерейная модель (главная «продаёт» работы и заявки).
**Модель:** один домен `имя.com`, коммерческий магазин — вторичным разделом.
**Основание:** `analysis-artist-websites.md`, `data/sites-technical.csv`,
`data/wikipedia-demand.csv`.

> Принцип: **сначала один домен, одна воронка, одна кнопка.** Второй путь
> добавляется секцией, а не вторым сайтом. Звёзды выборки теряют спрос
> (11–83 тыс./мес) именно на раздробленных или заброшенных сайтах.

---

## 1. Главная: галерейный приоритет

Первый экран отвечает на вопрос «кто это и которую работу я могу запросить»,
а не «что можно купить».

| № | Блок главной | Содержимое | CTA |
|---|---|---|---|
| 1 | Шапка | логотип-имя + меню: Works · Available · About · Exhibitions · Press · Contact (**Shop последним**) | — |
| 2 | Hero (первый экран) | одна сильная работа: название, год, техника, размер | [ Смотреть работы ] [ Available works ] |
| 3 | Избранные работы | 3–6 работ сеткой | карточка работы |
| 4 | Available works | актуальные лоты, «по запросу» | **Запросить** |
| 5 | Свежее | ближайшая выставка или новость | — |
| 6 | О художнике + пресса | короткий абзац, фото, цитаты, логотипы публикаций | — |
| 7 | Подписка (collector list) | email-поле, общее для обоих путей | **Подписаться** |
| 8 | Shop | принты/книги/товары — **ниже сгиба** | в `/shop` |
| 9 | Футер | контакты, Instagram | — |

Правило приоритета: если на первом экране нет работы и кнопки «Запросить» —
галерейная модель сломана. Товар и цена — это второй экран и `/shop`.

## 2. Карта сайта

| Раздел | URL | Назначение | Деньги |
|---|---|---|---|
| Работы | `/works` | архив, витрина, SEO по названиям | заявка |
| Доступные работы | `/available` | «inquire», актуальные лоты | **заявка** |
| О художнике | `/about` | доверие, биография, CV | — |
| Выставки | `/exhibitions` | свежесть, поводы для SEO | — |
| Пресса | `/press` | подтверждение статуса | — |
| Блог | `/journal` | техника, материалы, SEO | трафик |
| Магазин | `/shop` | принты, книги, товары | **покупка** |
| Контакты | `/contact` | форма + email | заявка |

Обязательный минимум для запуска: `/works`, `/available`, `/about`, `/contact`,
`/shop` (можно в состоянии «скоро» с подпиской).

## 3. Разово: запуск

### 3.1 Домен и хостинг
- [ ] Домен `имя.com` (не поддомен галереи, не парковка, не «coming soon»).
- [ ] HTTPS с валидным сертификатом — проверено, не по умолчанию.
- [ ] Автопродление домена и сертификата включено.

### 3.2 Платформа
- [ ] Витрина: Squarespace / Cargo / WordPress (по вкусу и бюджету поддержки).
- [ ] Магазин: Shopify (основной) — подключается как `/shop`.
- [ ] Один язык на старте; второй язык только при зарубежном спросе.

### 3.3 Структура
- [ ] Меню в порядке из раздела 1 (галерейное первым).
- [ ] `/available` существует и пополняется.
- [ ] Форма `inquire` подключена к рабочей почте.
- [ ] Подписка на рассылку в футере и после «Available works».

### 3.4 Контент
- [ ] 6–12 работ: изображение, название, год, техника, размер.
- [ ] Биография: короткая (2–3 абзаца) и полная (+ CV).
- [ ] Фото автора, пресс-цитаты, логотипы публикаций.
- [ ] Цены: в `/available` — по запросу; в `/shop` — показаны.

Изображения берутся из `assets/works/` (`web/` — для страниц, `thumbs/` — для
сеток); что уже готово к публикации, а что нужно доснять — в
`assets/works/inventory.csv` и `assets/works/README.md`.

### 3.5 SEO-минимум
- [ ] `<title>` с именем на каждой странице, `meta description`, `canonical`.
- [ ] OG-теги (корректный превью в соцсетях и мессенджерах).
- [ ] `robots.txt` — 200 и **не** `Disallow: /`.
- [ ] `sitemap.xml` — 200 и реальный список URL (не мягкий 200 главной).
- [ ] Микроразметка Person / VisualArtwork / Product.

### 3.6 Скорость и мобильность
- [ ] `viewport` на всех страницах, адаптив проверен на телефоне.
- [ ] HTML примерно 20–160 КБ на страницу.
- [ ] Изображения: WebP, сжатие, ленивая загрузка.
- [ ] Веб-версии собираются скриптом `assets/works/tools/optimize-images.ps1`
      (WebP + ресайз; нужен `cwebp` из libwebp).

### 3.7 Путь к деньгам
- [ ] `/available` + `inquire` — работает.
- [ ] `/shop`: корзина, оплата, доставка, налоги — для принтов и товаров.
- [ ] Тестовый заказ и тестовая заявка пройдены.

### 3.8 Аналитика
- [ ] Цели: старт · просмотр работы · заявка · покупка.
- [ ] Отслеживание источника трафика (Instagram, поиск, рассылка).

### 3.9 Запуск
- [ ] Проверка по таблице приёмки (раздел 6).
- [ ] Анонс в рассылке и Instagram.
- [ ] Редиректы со старых URL, если сайт существовал.

## 4. Регулярно: месячный ритм

| Задача | Частота | Время | Приоритет |
|---|---|---|---|
| Продажи и ответы на заявки | неделя | 1–3 ч | 🔴 |
| Обновление `/available` | месяц | 1–2 ч | 🔴 |
| Выставки / новости | месяц | 2–4 ч | 🟠 |
| Запись в `/journal` | месяц | 2–4 ч | 🟠 |
| Рассылка collector list | квартал | 2–3 ч | 🟠 |
| Бэкап, плагины, сертификат | месяц | ~1 ч | 🟡 |
| Ревизия аналитики | квартал | 1 ч | 🟡 |

**Итого: 5–8 часов в месяц.** Это ритм, который вывозит один человек.
Если план переваливает за 12 ч/мес — сокращать контент, а не заводить второй сайт.

### Минимум жизнеспособности
Даже в загруженный месяц обязательны только два пункта: **ответить на заявки**
и **обновить `/available`**. Всё остальное может подождать квартал.

## 5. Кто что делает

| Задача | Владелец | Можно отдать |
|---|---|---|
| Тексты о работах, рассылка | художница | нет |
| Съёмка работ | подрядчик | да, раз в квартал |
| Вёрстка, дизайн, правки | подрядчик | да, по часам |
| Настройка Shopify, аналитики | подрядчик | да, разово |
| Оплата, доставка, налоги | художница + бухгалтер | частично |
| Бэкапы, обновления, сертификат | сервис / подписка | да |

## 6. Критерии приёмки (измеримо)

| Проверка | Порог | Как проверить |
|---|---|---|
| HTTPS | валидный сертификат, HTTP 200 | браузер без предупреждений |
| Домен | `имя.com`, живой контент | открывается без заглушки |
| `viewport` | есть на всех страницах | `curl` + grep |
| `robots.txt` | 200, без `Disallow: /` | открыть файл |
| `sitemap.xml` | 200, реальные URL | открыть файл |
| title/description/canonical/OG | все заполнены | просмотр кода |
| HTML | ~20–160 КБ | DevTools → Network |
| Путь к деньгам | `inquire` **и/или** корзина | тестовая заявка/заказ |
| Подписка | форма работает | тестовая подписка |
| Микроразметка | Person / VisualArtwork / Product | Rich Results Test |

## 8. Отложенные решения

- **Второй язык** — только при подтверждённом зарубежном спросе.
- **Отдельный бренд/проект** — единственный оправданный второй домен
  (пример `chloewise.com` = «Extrasensory»), но это второй продукт, не вторая
  версия сайта художницы.

### Когда включать полную кассу (`/shop`)

| Объём продаж | Решение |
|---|---|
| 0 – несколько принтов в год | только `/available` + `inquire`, оплата счётом |
| Регулярные принты / книги / товары | полный Shopify в `/shop` |
| Уникальные работы **и** мерч | оба: `/works` (inquire) и `/shop` (корзина) |
